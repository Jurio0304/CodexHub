## Highlights

- Fixed column alignment in expanded GPU process tables, including hosts with multiple users.
- Added each process's runtime between its name and CPU load. Collapsed user rows continue to show the longest runtime among that user's processes.
- Batch host tests now refresh each host's connectivity and remote details as soon as its test completes. Shared actions stay busy until the batch finishes reconciling its results.
- Single-host and batch tests now share the Monitor sample timeout: 30 seconds by default, configurable from 1 to 60 seconds. This setting applies to the initial SSH check, each parallel probe group, and the concurrent latest-version lookup.

## Assets and updates

- Windows x64: `CodexHub_0.5.7_x64-setup.exe`.
- macOS Apple Silicon: `CodexHub_0.5.7_aarch64.dmg` for installation; `CodexHub.app.tar.gz` is for the in-app updater.
- Ubuntu/Debian: `CodexHub_0.5.7_amd64.deb` and `CodexHub_0.5.7_arm64.deb`.
- `latest.json` contains signed updater entries for Windows x64, macOS Apple Silicon, and both Linux architectures. `SHA256SUMS.txt` provides asset checksums.

Updater signatures verify update integrity and are separate from operating-system code signing. The macOS package remains unsigned/ad-hoc; Apple Developer ID signing and notarization are not configured. On first launch, macOS may require Control-click > Open or approval in Privacy & Security.

## 更新亮点

- 修复展开 GPU 进程表的列对齐问题，覆盖多用户主机的显示场景。
- 在进程名与 CPU 负载之间新增每个进程的运行时；用户行折叠时继续显示该用户进程中的最长运行时。
- 一键测试中，每台主机完成后立即刷新连通状态与远端详情；共享操作在整批结果同步完成后恢复。
- 单台与批量主机测试统一使用监控页的采样超时，默认 30 秒，可设置为 1–60 秒。初始 SSH 检查、各并行探测组及同时进行的最新版本查询均使用此设置。

## 下载资产与自动更新

- Windows x64：安装 `CodexHub_0.5.7_x64-setup.exe`。
- macOS Apple Silicon：使用 `CodexHub_0.5.7_aarch64.dmg` 安装；`CodexHub.app.tar.gz` 用于应用内更新。
- Ubuntu/Debian：使用 `CodexHub_0.5.7_amd64.deb` 或 `CodexHub_0.5.7_arm64.deb`。
- `latest.json` 提供 Windows x64、macOS Apple Silicon、Linux 两种架构的签名更新信息；`SHA256SUMS.txt` 提供资产校验值。

自动更新签名用于验证更新文件完整性，与操作系统代码签名分别管理。macOS 包仍为 unsigned/ad-hoc，尚未配置 Apple Developer ID 签名和 notarization；首次打开时可能需要通过 Control-click > Open 或“隐私与安全性”允许运行。
